Nibras PDF Test Fixture — Page 1

This is a small test PDF created to verify that Nibras can open a PDF file, extract its text client-side using pdf.js, and display it page by page in the reading view.

If pagination is working correctly, this page's text should appear as "Page 1" in the Reader, and a Next button should move to the following page.

Page 2 — English content

The second page exists to confirm that multi-page extraction works, not just the first page. Each PDF page should map to exactly one Reader section.

A lighthouse keeper checks the lamp every morning before dawn, regardless of the weather, because the one morning she skips is the one morning a ship might need the light most.
